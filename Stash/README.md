## 未转换

- **插件模块跳转**（surge-loon-to-egern）：作用是把可莉/QingR 插件中心的安装链接改成 Egern 的，Stash 不能直接安装 Loon 插件或 sgmodule，转了也没用
- **服务器监控**、**中国移动仪表盘**：Egern 专属的小组件（widget + Egern 脚本 API），Stash 没有对应功能
- **淘宝去广告**、**Auto_Join_TF**（kelee.one 的 Loon 插件）：kelee.one 对非 Loon 客户端返回 Cloudflare 拦截页，拿不到源文件。番茄小说、高德地图已用本仓库自己的模块替代

## 转换差异

- Surge 的 `extended-matching`、`pre-matching` 在 Stash 里没有，已去掉
- HTTPDNS拦截器 的 4 条 `USER-AGENT` 规则 Stash 不支持，未转换；`URL-REGEX` 规则改成了 url-rewrite reject
- Map Local 返回 `{}` 的改成 `reject-dict`，返回透明图的改成 `reject-img`
- YouTube增强、Telegram跳转 的模块参数按原配置写死在 `argument` 里；Telegram 用的是改写成 Stash 脚本 API 的 `scripts/TgRedirect.js`
- 小红书去广告 的脚本放在 kelee.one，如果 Stash 拉取失败（同样可能被 Cloudflare 拦）需要换成其他地址
